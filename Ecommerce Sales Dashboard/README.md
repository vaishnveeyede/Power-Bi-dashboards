# 📊 Ecommerce Sales Dashboard

This **Power BI dashboard** provides insights into ecommerce sales, profit, and order trends across different product categories, states, and customer segments.

## 🚀 Key Insights
- **Total Sales**: $21.32M  
- **Total Profit**: $2.43M  
- **Total Order Quantity**: 206.85K  
- **Top Product Categories by Profit**:  
  - Office Supplies  
  - Furniture  
  - Technology  
- **Top 5 States by Sales**: California, New York, Texas, Pennsylvania, Washington

## 📑 Features
- Sales & profit analysis by product category  
- Order quantity trends over time  
- Top states by sales performance  
- Segment-wise filtering (Consumer, Corporate, Home Office)  
- Interactive maps for sales by state  

## 📊 Dataset Information
- **salesdata_ecommercesite.csv** → Contains order-level sales and profit details  
- **state_codes.csv** → Mapping of states for visualization

## ⚙️ Tools Used
- **Power BI Desktop** (Visualization & Modeling)  
- **MySql** for data source  

## 📌 How to Use
1. Clone this repository  
2. Open `ecommerce_sales_dashboard.pbix` in Power BI Desktop  
3. Explore the interactive visuals
